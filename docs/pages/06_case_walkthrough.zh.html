01

最初的问题

这里有三层，必须分清楚。科学命题是写给人看的；被评测的轴是 agent 必须自己凿出来的； 而agent 真正读到的那段文字比前两者都短得多，也刻意得多。

LAYER 1 · 科学命题

写给人的那句话

TdT 与 Pol mu 是 Pol X 家族里的一对旁系同源酶，折叠几乎相同、催化化学相同，行为却不同。 哪些关键残基决定了这个差异？仅凭序列 + 结构 + 进化分析，能不能得出结论？

这是本 benchmark 的立题。注意它已经预设了「有关键残基」——而答案键的结论是：这个预设在残基层面部分为假。
LAYER 2 · 被评测的轴

agent 必须自己选出来

「催化活性不同」不是一个可测量。它至少可以拆成七条互相独立的轴。 benchmark 只在其中一条上计分：template-dependence of synthesis in cis（顺式合成的模板依赖性）。

这条轴不写在题面里。选错不在 DX01 扣分，而是让你后面填的每一条排除理由都对错了对象。
LAYER 3 · agent 读到的

两句话，外加四项作业

没有序列，没有结构，没有文献，没有表型数据，工具在 harness 层被封死，transcript 全程留档。 它只知道：同一个聚合酶家族的两个旁系同源物，折叠与化学相近，催化行为不同。

明化臂会告诉它这两个酶叫什么；盲化臂连名字都不给，只给 XP-A / XP-B。

七条轴，只有一条计分

活性轴状态为什么
顺式合成的模板依赖性计分轴这是 TdT 与 Pol mu 真正分开的地方：一个在无模板的 3'-OH 上加核苷酸，一个补缺口。全部 100 分挂在这条轴上。
糖选择性（2'-OH 歧视）排除Gly–Trp 门控是真的决定子，但它把 TdT + Pol mu 一起与 Pol beta / Pol lambda 分开——支系级，极性反了。
保真度与移码倾向排除不同的测量对象，不是同一条轴上的不同答案。
dRP-lyase 化学排除同上。Pol mu 的 8-kDa 结构域带弱 dRP-lyase 性质，但那是另一条轴。
金属偏好排除Co2+ 挽救实验在答案键里出现，但作为判定工具，不作为被评轴。
BRCT 介导的 NHEJ 招募排除BRCT 结构域两者都有且都必需。
末端桥接排除与模板依赖性相关但可分离；8-kDa N 端延伸的末端桥接功能是独立表型。

AMENDMENT · 允许迭代

修正是能力，不是违规

锁序允许修订，条件是：修订本身是一条带时间戳的日志条目，并点名触发它的那次测得失败。

这条是刻意写进去的——这个案例的真实历史正是这样走的：侧翼区域来自一次两亚家族比对，早于任何诱变；而机制改口发生在结构解出来多年之后。一个不允许中途改口的 benchmark 不可能奖励真实的科研行为。

分层评估：两条轴，同一批 100 分

阶段轴 S0–S5 是诊断轴，给人看：agent 到底卡在哪一步。 题型轴 T1–T11 是效度轴，给机器算：多少分是解析的、多少分是抽奖、多少分是 judge。 任一轴单独看都会误导——只看阶段，看不出某一阶段是被可猜的题型撑起来的；只看题型，看不出诊断。

S0 为什么是 0 分

先验已饱和。9/9 闭卷探针都点名 Loop1 为主导决定子，边界在两个蛋白里都大致正确； 催化天冬氨酸排除在每个做排序的探针里都是主动给出的；两个植入的支系诱饵被 3 个模型中的 2 个以正确的系统发育极性排除； in-trans 机制改口由 4 个探针产出，其中一个点名引用了那篇结构工作。

另外，A1-SCHEMA 臂实测「注入一个假设 schema 的增量价值」约等于零。在这里付钱＝给先验付钱。

S0 是 PASS/FAIL。FAIL 把整个 campaign 封顶在 40，并作废 S1 的枚举项与 S5 的提名、迁移格。但原始阶段向量仍然并排打印，带传播掩码，这样读者能分清「得不出结论」与「被上游作废」。
S3 为什么最重（25）

闭卷基线在这里是零，且在几何与缺陷上是负的。9/9 探针零个正确量级：没有一个特异性指数、速率常数、米氏常数或倍数被产出； 碰到数字的探针都自己标了不可靠。每个探针都至少产出一次自信的捏造。

奖励密度被刻意调高：让约三十个独立重算出来的数承载权重，而不是三个可引用的倍数。 典型题是：拿已发表动力学表的三个重复值自己重算一遍——会浮出两个没人报过的缺陷，一个印出来的平均值不是它自己三个测定值的均值，表的两半用了不同的标准差约定。两者都不可背诵，只有真跑算术才掉出来。

S5 拆成两段，因为「哈希封存的证据前先验」不是结论

S5a · 预言机前锁定

按预测与校准计分：对 agent 自己提名的那一组位点做三分类、在有约束力的申报预算下给出排名、以及校准项。

S5-A = 10 × clamp(raw/56, 0, 1) raw = 3·TP + 2·TN − 2·FP_negative 外加 每把一个 Loop1 内部阴性叫成 switcher 固定 −1，施加在比例项之外 —— 这样设计最锋利的陷阱不会被 归一化悄悄除掉。 负分信用上限 = 链闸下实际挣得的阳性信用 链闸 = 覆盖此处每一行的零分全局乘子
S5b · 预言机后修订

不锁定，对着实际释放的证据计分：修订后的结论、held-out 支系判定、规则修订连接、机制细节、可计算性判决。

这一段是 benchmark 里两处奖励「改口」的地方之一（另一处是下面的 S4-H）。S5a 与 S5b 的差本身就是一个被报告的量—— 一个前后完全不变的 agent，和一个被证据推着走的 agent，在这里读数不同。

S4 里还有一条新通道 S4-H（2 分）：一个 agent 在 S0 并不持有、在某条具体的已存盘证据记录之后才注册、并以该记录为触发器、随后被一次差异化 oracle 释放支持的假设。冷基线在这里是构造性的真零——没有探针跑过 campaign，所以没有探针能中途注册任何东西。
05

十一种题型，以及每种的一道真题

规则：对因变量做封闭，对自变量做生成。用强制选择去钉死 agent 已经生成的主张，绝不用它去替 agent 生成主张。

算术：提名维的原始量程是十阳性 ×3 + 十三阴性 ×2 = 56。实测生成地板是硬零（9/9 探针零个阴性）。 一旦把它变成那二十三个可计分位点的票面：纯三分类随机 10.0/56；一条「全答 reduced_activity_only」的单词退化策略拿 26/56 = 最大值的 46%，且不触发任何惩罚（−2 只对「把阴性叫成 switcher」触发）；一个零研究的芳香族启发式拿 34–41/56。 一个被工程成「全设计最干净的零」的维度，在题目集被供出的那一刻获得约一半满分的地板。推广到各维，朴素 MCQ 会让 63–67 分进入风险。

最锋利的反例是编号维：它是唯一实测基线为负的维度（自信的错答＝最大分离）。一个四选一票面按构造把地板抬到 25%。那等于花掉全 benchmark 最值钱的地板，去买一个 void 规则已经确定性提供的判分便利。

最终采纳 MCQ 的七处，全部在因变量上

  1. 对 agent 自己提名位点的三分类表型（10 分）——票面是标签，永远不是位点清单
  2. held-out 支系分类，选项 {templated, template-independent, both, insufficient from sequence}（3.5 分）——both 是承重的，二元先验不会主动给
  3. agent 自己浮出缺陷之后的裁决方向三分类 {prefer_record, prefer_prose, unresolvable}——键里三种都有实例，所以没有常数策略能赢
  4. 正确答案是「已记录 NULL」的参照系项
  5. 只能靠索引 FASTA 判定的构件 vs 全长与野生型 vs 嵌合体残基身份项——严格优于自由文本，因为自由文本允许复述口号而从不对某个位点下注；干扰项是真实的邻近残基
  6. 挂靠纪律的量纲项——干扰项是被安到错构件上的真实数字；认出那个数字对「哪个构件拥有它」毫无增益，而挂靠纪律正是捏造维真正的考点
  7. 从 agent 自己注册的假设里抽出的证伪方向项——选项集是 agent 自己的对象，不可能泄漏键

机制口径（必须是当前版本）

TdT 是模板厌恶（template-averse），不是绝对模板独立。 在突触结构里，N 端结构域与 Loop1 桥接两个 DNA 末端， in trans 提供一个模板碱基，并把微同源搜索区限制为 两个碱基对（一个微同源 + 一个新生），不是一个。 Loop1 明确不是伪模板：它用直接接触稳定微同源碱基对， 引物链楔子由小鼠 TdT Leu398 与 Phe405 构成。 同一工作提出一个有序水网络，使掺入可以独立于 in-trans 模板碱基进行 —— 所以 in-trans 模式是条件性且低保真的。 陷阱：Loc'h 2019 的「Loop1 碱基选择模型」读起来像 TdT 结果， 实际是用一个携带小鼠 Pol mu Loop1 的 TdT 嵌合体做的， 并且是为 Pol mu 提出的，不是野生型 TdT。 陷阱：野生型小鼠 TdT 是 Asp379 / Leu381 / Lys403。 Gln379 / His381 / Arg403 是嵌合体残基。 「Phe401/Phe405 夹住 His381」是嵌合体专属，且被野生型坐标反驳： 1JMS 的芳香簇是 Phe385–Phe401–His475（3.15–3.59 Å）， 而 Phe405 是一个独立锚点，距 Phe401 10.8 Å，堆在 Leu381 上。

可计算性判决——这是答案键的结论句，也是整个 benchmark 的立论。

序列、结构与进化回收区域：Romain 在任何诱变之前就从一次两亚家族比对里推出了 SD1 与 SD2，8-kDa 口袋那一对是用同样方法推出来的——历史上成功过两次。

但它们不能识别出因果残基：没有任何东西把 F401 与 H400、Q402、C404、F405 分开，而其中三个是实验阴性。 诚实的残差必须点名这种不可分辨性、点名 D179/S187 的仅定性状态，并点名互反的、表型分辨的单残基诱变是收尾测量。

最后：FvPolX 根本没有 Loop1，却保留弱的模板独立延伸——所以在这个折叠里，Loop1 充分但不必要。

评分标准

权重不是选出来的，是被实测逼出来的。九个闭卷探针（三个模型 × 三类提问，零工具） 决定了哪些维度值零分、哪些扛权重。原则只有一条：只给一个同权重闭卷模型产不出来的东西付钱，而且只在证据链许可时付。

这批实测本身有一个必须先说清楚的限制，而且它是发布闸门上的一条。

那九个探针的prompt 没有保留。只有一个探针产物存活下来（probe:rank:opus，即本页第 09 节引的那份）， 所以第三方无法重新打分这个语料。键里每一条 rubric 的 cold_baseline_provenance 都逐字写着这一点。

后果是分界线必须画在这里：权重的顺序（哪些维度是零、哪些扛重）由这个语料论证，量级在 BASELINE-v2 存在之前不可在印刷品中辩护。 BASELINE-v2 是 release_gate 上与那 29 个未写 brief 并列的阻塞项。本页后文所有「9/9」「零个探针」「4 个探针」式的计数，都应在这条限制下阅读。

三条编号警告：一对两错

✓ 对 —— 而且是全篇最好的技术陈述

「小鼠 TdT（510 aa）与人 Pol mu（494 aa）不能用常数偏移互换，必须走结构引导比对而不是算术。」

核验：F-MT→F-HPM 的锚点偏移是 12（8-kDa 口袋 179→167、187→175）、13（palm His 342→329、三联体 343→330、345→332）、16（SD1 399-405→383-389、SD2 473-475→457-459、gate 449→433）。三个不同值，确实非常数。

它仍得 0 分——因为这一维付钱给从序列索引或字节可检记录位点推导出来的换算项，而这是一条凭记忆的惯例：无 artifact、无偏移整数。这是整份报告里最能说明 DELTA-X 在给什么付钱的一处。
✗ 错 · 漂移 −1

「较老的 TdT 文献用牛编号，与小鼠/人有偏移。」

核验：牛（P06526，509 aa）与人同系：P06526[398-404] = DHFQKCF = P04053[398-404]，而小鼠是 P09838[399-405]。

正确表述是 小鼠 = 人/牛 + 1（自 360 起）。把「小鼠/人」并成一个系才是错误所在。

✗ 错 · 漂移 −1（grader 漏掉的第二条）

「人 TdT 有长短异构体，差约 20 aa 的插入，所以人 TdT 的残基号可能偏移约 20。」

核验：那个 20 残基插入是小鼠的：P09838 带 VAR_SEQ 482 K → KGKTVTISPLDGKVSKLQKAL。人 P04053 的两个异构体差的是 VAR_SEQ 454 Missing——一个残基。

这是把小鼠的结构移植到人身上，并对 F-HT 系断言了一个捏造的量级。

减轻情节：即便在小鼠，该插入位于 482，在 Loop1（按本提交自报的 ≈384-398；键给出四种并存定义）、SD1（399-405）、SD2（473-475）下游，动不了任何计分锚点——所以这是一条错规则，不是一个错号。

还有一处近失，值得单独记录——它是捏造维应有行为的样板。

原文：「I have a weak, unreliable association with a Glu in the mid-450s in mouse TdT, which I would not rely on.」

核验：P09838[455-460] = QFERDL，所以 457 确实是 Glu，这个联想字面为真。 但小鼠 TdT 真正的糖门控是 G449/W450（P09838[448-454] = LGWTGSR），所以「mid-450s 的 Glu 作为 Pol mu gate 的 TdT 对应位」是错的—— 它正是九探针基线直接断言的那个 Glu457 捏造的对冲版本。

因为它被免责而非被断言，所以既不扣分也不给分。一个被免责的非断言不是断言。

为什么是零——以及为什么这正是设计想要的结果

FLOOR, NOT PENALTY

它落在地板上，不是被打下去的。DX05 的陷阱就是为惩罚「Loop1 是决定子 ⟹ Loop1 残基就是答案」这条推理建的——会一头撞上四个阴性，丢 8 分、一分不得。

Opus 给了区域（≈384–398）但拒绝在区域内部下结论。那个区间里含 T384、F385、P391、S392、D396——五个干净阴性——它一个都没分类。所以是 0 分，不是 −8 或 −10。

设计自己的 cold_baseline 正好预言了这个行为：「基线的特征性失败是反过来那一种——点名一个区域，拒绝在里面定位。」这个维度把两种失败都明码标价。
