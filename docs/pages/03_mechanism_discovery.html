OPEN HYPOTHESIS SPACE

从最初的 L2 产物现象，至少保留五类解释

H1

Exo-processive

酶从糖链末端逐步切除 L2。预测：终端堵塞对活性更敏感；初始结合位置靠末端。

H2

Endo-dissociative

酶在内部切割后释放糖链，再次随机结合；L2 优势可能来自底物/产物偏好。

H3

Endo-processive gating

先内部结合、再临时闭合活性隧道；切割后开门，剩余糖链保持结合并滑移。

H4

Static tight-binding tunnel

稳定的封闭隧道可保持底物接触；关键功能可能主要来自结合强度而非构象开关。

H0
未进入候选集合的机制

例如多位点协同作用、产物抑制或实验构型导致的表观模式。Agent 必须允许新证据触发假说集修订。

两类错误不能被掩盖

  1. 确认偏误：Agent 为已选择的机制不断累积支持性结果，忽略强反对证据。
  2. 机制过度断言：把单一突变的活性损失当成特定转位步骤的直接证明。
  3. 后验篡改：看到结果后修改原先的预测或判定阈值。
  4. 伪独立证据：将同一轨迹的不同图表计作多次独立重复。
  5. 数据泄漏：通过论文检索、PDB 元数据或 DOI 得到最终解释。

建议同时报告单独的 execution score 和 discovery score，避免科学探索中的负结果被工作流完成率掩盖。

字段是建议接口示例，具体类型约束可用 JSON Schema 固化。

Evaluator 的 5 道关口

  1. Lock：实验前锁定候选机制和相反预测。
  2. Authorize：检查科学可行性、必要对照与资源权限。
  3. Run：通过可信执行器产生新结果；观察与解释分离。
  4. Verify：核对来源、单位、统计和测量是否充分。
  5. Update：记录对每个假说的支持/反对方向、强度和理由。

模型可以提出实验和解释；grader 需要保留未经模型修改的原始测量，才能评估机制更新是否被证据支持。

VALIDITY TIERS

三种评测 Track：从复现走向真实发现

TRACK A / PUBLIC

Retrospective replay

已公开 GH158(Pro) 案例；逐轮提供论文已公开结果，只用来调试 orchestrator、工具调用、evidence log。

可复现性高 · 新发现有效性弱
TRACK B / BLINDED

Prospective mutational tests

在相同酶上设计未公布的隧道/转位关键位点突变、正交 binding / folding / kinetic 测定，并在 Agent 预测后完成实验。

能测可证伪的科学预测
TRACK C / STRONGEST

Held-out GH158 ortholog

选择尚无公开机制阐述的新 GH158 同源酶，使用未发表的结构/产物/动力学数据；Agent 从新的现象自行发现因果机制。

最接近真正的机制发现能力

WHAT COUNTS AS SUCCESS

最终输出应是可审计的机制档案

最终应提交

  1. 研究子问题与竞争机制集合（包括 H0）
  2. 各机制的可证伪预测与实验前登记
  3. 完整调用 ledger、原始数据来源、独立重复
  4. finding → hypothesis 的证据作用与冲突
  5. 状态转换式机制图与各边证据类型
  6. 仍未排除的替代机制、缺口与下一实验

可接受的部分正确结论

例如 Agent 可靠地证明了底物结合偏好 closed、突变改变产物谱，但没有足够证据确认 processive 转位的真实动力学。它应报告 门控得到支持，而完整过程性机制仍需验证。

这类校准良好的未完成结论，应优于无证据的完整故事。
