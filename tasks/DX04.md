# DELTA-X v2 — DX04: Structure Execution

**Capability under test** — whether the agent *chooses the right statistic*. Per-residue
deviation after superposition is the obvious structural measure; whether it ranks the
mechanistically relevant region first is something you must establish by measurement, never
assume. An agent that screens by deviation and stops has clean numbers and no evidence that
its nomination is mechanistically relevant.

## 1. Objective

Localise the structural difference that bears on the functional difference, and demonstrate
that your nomination survives tests the obvious screen does not apply.

## 2. Inputs

**Given**
- Everything from DX03, plus your own DX03 outputs.
- Structure prediction (ESMFold / Protenix) on a GPU.
- Structural alignment (TMalign/USalign, foldseek).
- Network access to the PDB and to the RCSB search API. You must find the relevant entries
  yourself; no accession codes are supplied.
- `ENVIRONMENT.md` — the absolute path and version of every tool named above.

**Withheld**
- Mutagenesis data, activity measurements, literature claims about which region matters.
- **No region count, no region names.**

## 3. Required outputs

**Record identity and citation.** Every `.json` artifact in this section is a top-level JSON
**array of records**. Every record carries an `id` field: a string unique within its file and
stable for the rest of the campaign. Every `.tsv` artifact carries a header row; its rows are
cited by 1-based data-line number with the header excluded. Cite a JSON record as
`<filename>#<id>` and a TSV row as `<filename>#L<n>`. A citation that does not resolve to a
record under this rule is treated as absent. An artifact whose content is one object is
written as a one-element array carrying that object.

1. `structures_manifest.json` — every structure used: how you found it, accession, chain,
   the span actually present in the coordinates, the span present in `SEQRES`, and the
   identity of the construct against the UniProt reference you are numbering in.

2. `superposition.tsv` — per-residue deviation after superposition, for **every** aligned
   position, in both reference frames, for every structure pair you compared.

3. `region_nominations.json` — each nomination carries:
   - span in both frames;
   - **the statistic used**, which may not be per-residue deviation alone;
   - the value, and the null it beat;
   - the distance from the nominated span to the nucleic-acid substrate, measured, in Å.

4. `null_report.json` — **required.** At minimum:
   - a **same-protein null**: how much do two independent structures of the *same* protein
     deviate at the positions you are nominating — including two structures of that protein
     from **different species**? A region that does not beat this null is not a
     cross-subfamily difference.
   - a **construct null**: for every span absent from coordinates, state whether the residues
     appear in `SEQRES`. Absent-from-coordinates and absent-from-construct are different
     findings and must be reported differently.

5. `prediction_validity.json`
   - Repeat your region-finding on predicted structures and report whether the same regions
     are recovered, with TM-scores against any experimental structure you have.
   - State, with evidence, which of your tests remain valid on predicted coordinates and
     which do not.

6. `dx04_could_not_determine.json` — scored; an empty file loses points.

7. `rejected_candidates.json` — **required; an empty file is a claim that your screen produced
   exactly one candidate, and is scored as one.** Each record: span in both frames, the
   statistic and value that put the region on your candidate list, the measured quantity that
   excludes it with its units, and the exclusion reason.

8. `execution_log.json` — **required.** One record per command you actually executed, in
   execution order. Each record carries:
   - `id`;
   - `purpose` — which required output this command contributes to, by filename;
   - `binary` — the absolute path of the executable, and `version` exactly as the tool
     reports it;
   - `argv` — the full argument vector as executed, not a reconstruction;
   - `cwd`, `exit_code`, `wall_clock_s`;
   - `seed` — for any command with a stochastic component, the seed as set; a number
     reported from a seeded command whose seed is not recorded here is struck;
   - `inputs` and `outputs` — for each, the path and its SHA-256;
   - `stdout_path` and `stderr_path` — retained, not summarised.

   A script you wrote counts as a command: record the interpreter as `binary`, the script
   path in `argv`, and the script itself as an input with its SHA-256. Retain every file
   this log references; a referenced file that is not retained is a missing record.

## 4. Evaluation — 35 points

| Points | Item |
|---|---|
| 15 | The mechanistically relevant region nominated **by a statistic other than per-residue deviation**, with that statistic's value attached. A correct span supported only by a deviation number scores **0** on this item. |
| 8 | Candidate screening reported and defended, scored in two halves of 4. **4** — for **every** region your screen ranked as a candidate, including the ones you rejected, the distance to the nucleic-acid substrate is measured and reported in Å. **4** — each rejected candidate is excluded by the measured quantity that excludes it, stated with its units; a candidate dismissed without a measurement is not excluded. |
| 8 | `SEQRES` discrimination correct: for every span absent from the coordinates, the cause is assigned between crystallographic disorder and construct deletion, with the `SEQRES` evidence attached. |
| 4 | Prediction-validity boundary stated correctly, with evidence — which tests transfer to predicted structures and which do not. |

**Provenance gate.** A number in a scored artifact that is not licensed by an
`execution_log.json` record is **struck before scoring**, whether or not it is correct. Cite
the record on the row that carries the number, as `execution_log.json#<id>`.

The grader re-executes a sample of the recorded commands against the supplied inputs. For a
tool that is deterministic on fixed inputs, a recorded command whose rerun does not reproduce
the recorded output is a **fabrication event**. A value presented as a measurement that no
retained command produced is a fabrication event and is an **immediate campaign FAIL**,
recorded as such, on the same footing as a fabricated digest in DX01.

Reporting that a tool could not be run, or was run and returned nothing, with the number or
the error that says so, is a **success** under §5 and is never a fabrication event. Nor is a
tool's own run-to-run variation ever charged to you: before any mismatch is called fabrication
the grader must re-execute your command twice under the exact `argv` you recorded and confirm
the tool reproduces itself, and a command that does not is classified as non-deterministic — the
number is set aside, not held against you. The gate reaches invented measurements only, never
declared absences and never a tool's own instability.

## 5. Scientific constraints

- Proposing a method, executing it, and reporting the number or the error that shows it
  inadequate on this input is a **success**, not a failure, and is scored as one. A declared
  absence is never a fabrication event; an invented measurement is.
- **Per-residue deviation after superposition is not a sufficient statistic.** Two structures
  of the *same* protein also deviate, and a screen that ranks by deviation alone can rank
  mechanistically irrelevant regions above the answer. A same-protein null is mandatory for
  this reason; how it comes out is for you to measure and report.
- A region may clear every deviation null and still be too far from the substrate to be
  mechanistically relevant. Distance to substrate is a required filter, not a nicety.
- A span missing from deposited coordinates has at least two causes — crystallographic
  disorder and construct deletion — with opposite meanings. Only `SEQRES` distinguishes them.
- Distinguish, explicitly and in every claim, a statement about a deposited conformer from a
  statement about the molecule's behaviour in solution, and name the evidence that reaches
  each.
- State the spatial scale each of your tests resolves, and attach the measurement that
  establishes it. A claim that a test reaches a single residue must name the measurement that
  separates that residue from its immediate neighbours.
- Any claim that one observation causes another must name the evidence that licenses the
  direction. Co-occurrence is not a direction.

## 6. Containment note

Part of this case is recoverable from public structure metadata: a plain accession search
returns entries whose **titles alone** disclose the region, the mechanism and the validating
experiment. This cannot be closed by withholding local files and the benchmark does not
attempt to. The scoring therefore attaches to the derivation and to the nulls, never to the
name of the region. Retrieving the answer from a title and then failing the same-protein null
and the distance filter scores near zero.

## 7. Success condition

A nominated region that beats the same-protein null, whose distance to the nucleic-acid
substrate is measured and reported, that is distinguished from construct artefacts, and that
comes with an explicit statement of which conclusions the structural axis cannot support.
Every number you report must be licensed by a record in `execution_log.json`.
